# Deadlock gameinfo.gi research, 2026-10-06

State of the art for tuning Deadlock through `gameinfo.gi` as of 2026-10-06 (game build 6753, 2026-10-05), checked
against Valve's own files rather than guides. Companion documents:

- [BLOCKED-CONVARS.md](BLOCKED-CONVARS.md): the 77 convars the game now ignores when set from `gameinfo.gi`.
- [CONFIG-COMPARISON.md](CONFIG-COMPARISON.md): line-by-line comparison with twelve other public configs.
- [TUNING-CANDIDATES.md](TUNING-CANDIDATES.md): what is left to test on this repo's hardware, and what not to bother with.
- [`data/convar-matrix.csv`](data/convar-matrix.csv): every convar any config sets, with Valve's default and flags, across all configs.

Primary sources were Valve's tracked game files in [SteamTracking/GameTracking-Deadlock](https://github.com/SteamTracking/GameTracking-Deadlock)
(convar dumps, stock `gameinfo.gi`, localization, GC protobufs), the config repositories themselves, and the
DeadTune catalogue. Several community sites (the official forums, SteamDB, GameBanana, Steam Community, X, Reddit,
patch-note aggregators) were unreachable from the research environment; where they are cited, it is through search
snippets only, and that is marked.

## TL;DR

1. **The matchmaking guard does not cover ConVars.** Valve's string said "changes to ConVars" for exactly one day
   (2026-03-26, build 6416) and has read "unsupported changes to the following sections: Engine2, MaterialSystem2,
   NetworkSystem, Particles, RenderSystem, SceneSystem, WorldRenderer" since 2026-03-27 (build 6417). The
   "2026-07-31" date in this repo's older notes was wrong. Whether the guard is actively enforced is still unclear
   (section 1).
2. **Valve closed the exploit convars a different way.** Since the 2026-09-24 depot update, 49 convars (77 after City
   Never Sleeps) carry `gameinfo_cannot_override`: the game ignores them when they come from `gameinfo.gi`. They are
   the wallhack-adjacent ones (enemy outlines, glow, cloak, `r_shadows`, `r_drawparticles`, fog master switches,
   `sv_cheats`). This repo's config hits none of them. Every other public config still carries between 1 and 31 dead
   lines because of it (section 2).
3. **The frame-time levers this config uses still work.** Shadow quality and cascade overrides, SSAO, `fog_enable`,
   grass, clutter, LOD bias, particle fallbacks and texture filtering are not flagged.
4. **Compared with the field**, this repo is the only config with zero dead lines and zero guarded-section edits.
   It is also the most conservative on lighting (keeps dynamic and stationary lights, shadow casting and sun) and the
   only one that refuses culling cuts that hide objects. Everything else is a matter of degree (section 4).
5. **`video.txt` is the second config layer** and is what the in-game menu writes. Community configs ship one.
   Some of its keys name convars that are blocked from `gameinfo.gi`; whether the video path still applies them is
   untested (section 5).
6. Nothing in the Oct 1 to Oct 5 hotfixes touched a performance convar; the additions are subtitles, HUD smoothing
   and colour settings (section 3).

## 1. The matchmaking guard (PGI verification)

### Timeline from Valve's localization file

`game/citadel/resource/localization/citadel_main/citadel_main_english.txt`, key `Citadel_StartMatchmaking_UnverifiedPGI`:

| Build | Date | Text |
| --- | --- | --- |
| 6395 | 2026-03-14 | key absent |
| 6416 | 2026-03-26 | "Unable to enter matchmaking while any party member has changes to ConVars in gameinfo.gi or is running Tools-mode." |
| 6417 | 2026-03-27 | "Unable to enter matchmaking while any party member is running Tools-mode, or has unsupported changes to the following sections of their 'gameinfo.gi': Engine2, MaterialSystem2, NetworkSystem, Particles, RenderSystem, SceneSystem, WorldRenderer" |
| 6462, 6652, 6660, 6753 | Apr 28 to Oct 5 | unchanged from 6417 |

The one-day "ConVars" wording is what the `@deadlock_8` post of 2026-03-26 and the FOV backlash on X and the forums
reacted to (search snippets; the tweet IDs decode to 2026-03-26 18:09 to 20:24 UTC). Sqooky's README still quotes that
wording in its "Pretty Important Announcement" and calls it "not fully implemented"; that paragraph is seven months
stale. The guides that say "ConVars are restricted" are repeating the March text.

### The wiring

`Protobufs/citadel_gcmessages_client.proto` (build 6753):

- `CMsgCitadelClientHello { bytes pgi_hash = 1; bytes pgi_version = 2; }`: the client reports a hash of its
  `gameinfo.gi` and the `PGIVersion` key on every GC hello.
- `CMsgClientToGCStartMatchmaking { ... bool pgi_verified = 6; }` and `CMsgClientWelcomeCitadel { ... bool pgi_verified = 5; }`.
- `CMsgClientToGCStartMatchmakingResponse.EResultCode.k_EResult_UnverifiedPGI = 26` (and a second enum value
  `k_eUnverifiedPGI = 32` elsewhere in the file).
- Valve's stock `gameinfo.gi` carries `PGIVersion "39A735A4...FA0C"` since City Never Sleeps (it was
  `5F91238F...6957` from July). The key `DisallowGameInfoConditionals 1` was removed in City Never Sleeps.

### Is it enforced?

Evidence points both ways and none of it is conclusive:

- This repo's notes (2026-10-05) say "not enforced", presumably from play-testing with upstream's edited engine sections.
- DeadTune's README says the game "only refuses to queue when [the seven sections] are changed" since March 2026,
  "checked on Windows". But its own Status section lists "whether matchmaking refuses to queue with practice mode on"
  (which edits SceneSystem) as an open question, so the author has not verified it either.
- Sqooky's, OptiLock's, Kaizuchaneru's and Boot's configs all ship edited guarded sections and have active user bases.
  A search of Sqooky's issue tracker for "matchmaking" returns nothing; the 20 most recent issues are about crashes,
  HUD and camera, not queueing.
- A forum thread titled "NetworkSystem being blocked by the PGI change slightly hurts Dedicated servers over P2P"
  exists (unreachable here), which implies the check does something for at least that section.

Working conclusion: the mechanism is live on the wire, the client knows whether it is verified, and the GC can refuse
the queue, but as of early October 2026 no public config author reports being refused. Keeping the seven sections
byte-identical to stock, as this repo does, is the only setup that is safe under every reading. Keep it.

## 2. `gameinfo_cannot_override`: how Valve actually disarmed the config exploits

Counting the flag in Valve's `DumpSource2/convars.txt` across commits:

| Dump commit | Date | Build | Flagged |
| --- | --- | --- | --- |
| `5bad95d` to `a1139b2` | Jul 31 to Sep 18 | 6660 to 6698 | 0 |
| `711b91e` | 2026-09-24 | 6698 (silent depot update; no patch notes that day) | 49 |
| `58b3529` | 2026-09-29 | 6711, City Never Sleeps | 77 |
| `2a29281`, `8c7cf4e` | Oct 2, Oct 5 | 6736, 6753 | 77 |

The semantics follow from the name and from DeadTune's independent testing ("the game also ignores 77 ConVars when
they are set in gameinfo.gi"): the line parses, but the engine refuses the override. The full grouped list and the
re-check procedure are in [BLOCKED-CONVARS.md](BLOCKED-CONVARS.md).

What this means for performance tuning:

- Blocked and gone for good from `gameinfo.gi`: `r_shadows`, `csm_max_shadow_dist_override`, `sc_disable_spotlight_shadows`,
  `r_enable_volume_fog`, `r_enable_cubemap_fog`, `r_enable_gradient_fog`, `r_particle_max_detail_level`,
  `r_particle_multiplier`, `r_drawparticles`, `r_drawskybox`, `r_directlighting`, `r_postprocess_enable`,
  `r_nearz`, `r_citadel_gpu_culling*`, the `r_citadel_distancefield_*` family, `r_citadel_depthoffield_*`,
  `r_citadel_mboit_quality`, `mat_fullbright`, `sv_cheats`.
- Still working: everything this repo relies on. Verified by intersecting the active and commented lines of
  `gameinfo.gi` with the list: zero hits.
- Four convars from the first batch were themselves removed or renamed in City Never Sleeps
  (`citadel_player_anim_debug`, `citadel_player_glow_when_in_combat`, `..._linger`, `r_citadel_cosmic_veil_fade_dist`).

Most of the 77 are also `cheat`-flagged, so the console path needs `sv_cheats 1`, which only works offline. The
`video.txt` path is discussed in section 5.

## 3. What changed in Valve's files since this repo's last audit

### Stock `gameinfo.gi`, July 30 (build 6652) to September 29 (build 6711)

Beyond the `PGIVersion` change and `DisallowGameInfoConditionals` removal:

- FileSystem: `Game_Language` became `Game_UILanguage` (with `Game_LowViolence citadel_lv`); `UserSettingsPathID "USRLOCAL"`
  and `LegacyUserSettingsPathID "MOD"` became explicit keys. Deadlock Mod Manager adopted the same two lines in its
  SearchPaths template (PR #779).
- MaterialSystem2: new render mode `game ShadowSilhouette`.
- RenderSystem: `SwapChainSampleableDepth`, `GraphicsPipelineLibrary`, `VulkanOnly_Linux` and the three
  `VulkanSteam*ShaderCache` keys plus `VulkanAdditionalShaderCache` were dropped from stock.
- Engine2: added `PauseOnCtrlConsole 0` and `MapMaxCoord 32768`.
- SceneSystem: `LayerBatchThresholdFullsort`, `DisableLateAllocatedTransformBuffer` and
  `MinimumLateAllocatedVertexCacheBufferSizeMB` were dropped; the first moved to the convar
  `sc_layer_batch_threshold_fullsort "20"` in the ConVars tail.
- Particles: added `BindlessParticleShader 1`. New `Physics { EnableWorldCompounds 1 }` section.
- ResourceCompiler: Steam Audio bake defaults expanded (reverb/pathing/custom data), `MergeTranslucents 1`,
  `BC6HHueShiftFixup` and `Repack2` dropped. ModelDoc lost the `animgraph` feature.
- ConVars tail: the networking block was reorganised; values match what this repo carries.

This repo's non-ConVars sections already match the new stock except for the deliberate SearchPaths additions
(`citadel/custom`, `citadel/addons`, explicit `Mod`/`Write`), confirmed by diffing section by section.

### Convars added or removed after City Never Sleeps (build 6722 to 6753)

Added (38): subtitle controls (`citadel_subtitles_*`, 14), unit-status smoothing and name fade
(`citadel_unit_status_offset_smooth_*`, `citadel_unit_status_name_fade_*`, `citadel_unit_status_hero_name_mode`,
`citadel_unit_status_release_delay_time`, `citadel_unit_status_offset_player_*`), enemy damage-delta and zipline
colours, `citadel_photomode_enabled`, `citadel_player_cam_toggle`, `citadel_crosshair_pip_gap_collapse`, ping and
settings-menu tweaks. None is a performance convar.

Removed (14): `fog_enableskybox`, `fog_colorskybox`, `fog_startskybox`, `fog_endskybox`, `fog_maxdensity`,
`fog_maxdensityskybox`, `fog_hdrcolorscaleskybox`, `citadel_unit_status_stamina_low_pips`,
`citadel_unit_status_stamina_low_show_window`, `citadel_minimap_use_effects`,
`citadel_damage_report_ignore_neutral_subclass`, `citadel_damage_report_ignore_trooper_subclass`,
`citadel_new_ping_coyote_time`, `r_particle_explicit_fetch`. This repo had already dropped the two it used.

The Oct 5 build (6746 to 6753) alone added 14 (all subtitles plus `citadel_player_cam_toggle`,
`citadel_crosshair_pip_gap_collapse`, `citadel_unit_status_release_delay_time`) and removed 3
(`citadel_minimap_use_effects`, the two `citadel_damage_report_ignore_*`).

### Patch notes

The 2026-10-05 patch (3 days after Rat King) was hero balance (Rat King, Sinclair). No graphics or engine notes
were found for the Oct 1 to 5 hotfixes (search snippets only; aggregator sites were unreachable). The Sep 24 depot update
that introduced the flag had no public notes.

## 4. The other configs, in one paragraph each

Full tables in [CONFIG-COMPARISON.md](CONFIG-COMPARISON.md).

- **Sqooky / OptimizationLock main** (this repo's upstream, 3.4 + cosmetic commits through 2026-10-06): the 19 value
  differences are all deliberate reverts here (lighting, sun, shadow casting, glows, viewmodel, tracers, textures,
  filtering, Steam Input, thread pool, FPS cap). 143 upstream tweaks are default here; most are either dead
  (30 nonexistent, 1 blocked), hide things (`r_farz`, `r_mapextents`, `sc_screen_size_lod_scale_override`,
  `r_size_cull_threshold`, `cl_ragdoll_limit`, `r_drawropes`), or UI resets. Upstream edits Particles, RenderSystem,
  SceneSystem and WorldRenderer. New since 3.4: an **auto updater** (`auto updater/gameinfo_updater.py`) that fetches
  the latest upstream file and applies an `overrides.gi` (lock a value, or force a line commented). Also new: Eskay's
  config as a preset, and a `test_cfg` that equals the Max FPS file.
- **Sqooky test_cfg / Max FPS**: adds the sunlight, mixed-shadow and precomputed-shadow kills, disables physics,
  ragdolls, dynamic lights, instanced meshes and HDR, hides unit names. Three of its fog lines are blocked. Not a
  model for a clarity config.
- **Kaizuchaneru minimum spec / extreme low**: FPS at any cost. 20 to 21 blocked lines, edits SceneSystem and
  WorldRenderer (shadow textures 0, cascades 1, transform texture rows 128, envmap face size 4096 with render size 1).
- **Boot's max FPS** (and `abyzzboyxdd/gameinfo.gi-ywususu`, which carries the same ConVars with three values changed: `r_aspectratio` 2.49 and the two dead `panorama_max_*fps` lines): 435 active
  lines, 26 blocked, 45 nonexistent, all seven guarded sections rewritten. Deprecated by its own author.
- **OptiLock (dacooderr)**: the largest (544 active, 31 blocked, 69 nonexistent), rewrites all seven guarded sections
  plus Hammer, ResourceCompiler, pulse and Localize, mounts a QoL VPK via SearchPaths, and *requires* its `video.txt`
  (mip bias 4 to 8, `gpu_level 0`, upscaling 0, all shadow/AO/fog menu keys off) plus a Sinner's-light fix mod.
  Its Oct 2 commits toggled `direct_light_shadows` in the ResourceCompiler block, which is a map-compile setting.
  Claims ~30% better 1% lows and ~40% average FPS on low/mid systems; no methodology published.
- **Piggy's**: small (136 active) but 11 blocked lines and all seven sections edited; the pastebin "competitive" version
  was unreachable.
- **compylock (7liv)**: competitive bundle (health-bar and stretched-res VPKs, `video.txt`, FOV via
  `citadel_camera_hero_fov 103` which the engine clamps to 90, and `r_aspectratio 2.4`). Based on a pre-CNS Sqooky
  file; 22 nonexistent lines.
- **Skip-eo/Deadlock-Config**: deprecated; autoexec and a 21:9 custom-resolution FOV trick, no gameinfo tuning.
- **txzy2/deadlock**: a Linux/Vulkan/gamescope personal config (raw files not fetchable at the default paths).
- **DeadTune (simulieren)**: not a config but a Rust editor with 9 presets (Sqooky stable/testing, Kaiz min/extreme,
  Boot, OptiLock recommended/potato, SideLock, Vanilla). Edits only the ConVars block and SearchPaths, tags each of
  772 catalogued convars as live / live-in-sandbox / restart / **ignored**, rates impact (16 high, 29 medium), imports
  Sqooky's `overrides.gi`, and has a "practice mode" that edits SceneSystem for offline play with a one-click
  "ranked-safe" revert. Its high-impact list and this repo's choices are reconciled in TUNING-CANDIDATES.md.
- **SideLock** (GameBanana, hitmeupwhenyourelonely): referenced by DeadTune as the config that moved shadow/fog cuts
  into SceneSystem after the convars were blocked. Licence forbids redistribution; not fetchable here.
- **DL-FOV-Fixer (lukr-99)**: tray app that re-inserts `r_aspectratio` into ConVars after updates.

Patterns worth copying from nobody: `cpu_level`/`gpu_level` (skip particle systems with a minimum level),
`r_farz`/`r_mapextents` (pop-in), `sc_screen_size_lod_scale_override` (holes in Victor and Paige per upstream FAQ),
`cl_ragdoll_limit 0` (breaks the Doorman ult indicator per upstream FAQ), `citadel_portrait_world_renderer_off`
(dark portraits).

## 5. The second layer: `video.txt`

With stock `UserSettingsPathID "USRLOCAL"`, the menu writes `Steam\userdata\<id>\1422450\local\cfg\video.txt`.
Keys are `"setting.<convar>" "<value>"` plus device IDs and resolution. Community configs (OptiLock, compylock,
Sqooky's test folder) ship one. Keys seen in those files, grouped:

- Menu-exposed: `r_citadel_shadow_quality`, `r_citadel_ssao_quality`, `r_citadel_fog_quality` (range 0 to 1),
  `r_citadel_antialiasing`, `r_citadel_upscaling`, `r_citadel_dlss_settings_mode`, `r_dlss_preset`, `r_effects_bloom`,
  `r_post_bloom`, `r_depth_of_field`, `r_citadel_motion_blur`, `r_texture_stream_mip_bias`, `r_arealights`,
  `mat_vsync`, `fps_max`, `r_low_latency`, `r_fullscreen_gamma`, `r_light_sensitivity_mode`, `r_reduce_flash`,
  `cpu_level`, `gpu_level`, `gpu_mem_level`, `mem_level`, `mat_viewportscale`, `r_citadel_fsr*`.
- Not in the menu but written when `useadvanced 1`: `shaderquality`, `r_citadel_half_res_noisy_effects`,
  `r_particle_depth_feathering`, `r_screen_space_shadows`, `r_citadel_distancefield_reflections`,
  `r_citadel_distancefield_shadows`, `r_citadel_distancefield_ao_quality`, `r_render_portals`,
  `r_displacement_mapping`, `r_env_map_uses_height_map`, `volume_fog_width/height/depth` (convar minimums 64/64/48,
  so compylock's "16" is clamped), `lb_shadow_texture_width/height_override`, `lb_dynamic_shadow_resolution`,
  `lb_enable_shadow_casting`, `csm_max_num_cascades_override`, `csm_viewmodel_shadows`,
  `lb_csm_override_staticgeo_cascades(_value)`, `cl_particle_fallback_base/multiplier`, `r_distancefield_enable`,
  `r_dashboard_render_quality`, `r_citadel_mboit`, `r_citadel_outlines`.
- Keys that name **blocked** convars: `r_shadows`, `csm_max_shadow_dist_override`, `r_particle_max_detail_level`,
  `r_particle_cables_cast_shadows`, `r_particle_shadows`.

Open question, worth one test: does the video-settings path apply a `setting.r_shadows 0` or
`setting.r_particle_max_detail_level 0` that `gameinfo.gi` can no longer set? The flag name says `gameinfo`, and
`video.txt` is Valve's own settings store that the guard does not hash. If yes, that is a legitimate, menu-equivalent
way to reach two large levers. If the engine validates against a whitelist, the keys are simply ignored. Nothing in
Valve's files answers this; it needs an in-game check (`r_shadows` in the console after launch).

Note that several `setting.*` keys (`shaderquality`, `r_screen_space_shadows`, `r_citadel_outlines`,
`r_citadel_motion_blur`, `r_reduce_flash`, `r_area_lights`) do not exist as convars in the dump at all, so they are
video-system settings, not convars, and cannot be set from `gameinfo.gi` in any case.

## 6. Launch options, checked against the engine

Upstream's `launch_options.txt` is Valve's command-line string table (1,536 entries), not a recommendation list.
Of the options guides recommend:

- Present in the engine: `-dx11`, `-vulkan`, `-novid`, `-high`, `-nojoy`, `-preload`, `-console`, `-condebug`,
  `-threads`, `-fullscreen`, `-windowed`, `-noborder`, `-w`, `-h`, `-refresh`, `-sdlaudiodriver`, `-nosteamcontroller`,
  `-no_texture_stream`, `-forcenovsync`, `-tools`, `-insecure`.
- Not present: `-m_rawinput` (a CS:GO-era option; Skip-eo's and some guides' recommendation does nothing),
  `-dx12`, `-lowend/-mediumend/-highend`, `-noaafonts`, `-novr`, `-cpu_level`.
- `+<convar> <value>` works for any convar regardless of the table, so `+fps_max 0` is valid but redundant with
  this repo's `fps_max "0"`.

Guides in 2026 converge on `-novid -high -nojoy` or just `-novid`; `-dx11` is the Windows default; `-vulkan` can win on
some AMD systems and is required for FSR3 frame generation; `-preload` is accepted but its benefit in Source 2 is
undocumented. The repo's current advice (keep it minimal, `-novid` at most) stands.

## 7. Tooling notes

- **Deadlock Mod Manager** (`game_config_manager.rs`): rewrites the SearchPaths block between
  `// Deadlock Mod Manager - Start/End` markers, or from the word `SearchPaths` to the first `}` if no markers exist.
  Its template puts `Game citadel/addons` first and does not include `citadel/custom`. If it is ever run against this
  repo's file it will replace the SearchPaths block with its own; everything else is left alone. Its validation checks
  only that `SearchPaths`, braces and the word `citadel` exist. The quote-count sensitivity mentioned in this repo's
  README was not found in this source file; it may live in a different parser or an older version. Treat as
  unverified, but keeping comments free of double quotes costs nothing.
- **Sqooky's auto updater** could replace the manual "re-apply CHANGES.txt on top of upstream" workflow: an
  `overrides.gi` with one line per deliberate difference (`r_rendersun 1`, `// r_farz`, ...) re-applies this repo's
  choices on top of whatever upstream ships. It does not restore the engine sections to stock, so a post-step would
  still be needed for that. The format is also importable by DeadTune.
- **Steam Audio**: `snd_steamaudio_num_threads` default in the dump is 2 (cheat-flagged); upstream's 6 and OptiLock's
  4 are not defaults for any hardware. Unchanged recommendation.

## 8. Known post-City-Never-Sleeps breakages reported upstream

Relevant to anyone running an OptimizationLock-derived file (issue numbers are Sqooky/OptimizationLock):

- #70 Rat King camera bugged with the config (fixed in 3.3 on 2026-10-02 by a camera convar change; this repo keeps
  camera convars at or near default and sets `citadel_camera_use_vmdl_flatten_vertical "true"`, the known-good value).
- #77 Minimap missing ziplines and troopers with config "version 2" (open; this repo keeps `r_drawropes` and the size
  cull threshold at default, which are the prime suspects).
- #78 Game freezes when hovering heroes in character select (open, cause unknown).
- #73 Things visible through the wrong side of veils (open).
- #63 The new white headshot particle disappears with the config (open). This repo runs the particle fallback system at
  upstream's aggressive values (`cl_particle_sim_fallback_threshold_ms 1`, multipliers 100/10/5), which is a plausible
  cause. If the headshot flash is missing in fights, comment those four lines out first.
- #76 Sinner's Sacrifice lights render as triangles when texture mip bias is high (fixed by HoppCX's mod; this repo
  runs mip bias 0, so not affected).

## 9. Hardware context

Aggregated community benchmarks list the Ryzen 7 9800X3D at roughly 249 average / 137 1% low FPS in Deadlock, the
second-fastest CPU tracked (howmanyfps.com, not config-specific). Team fights are CPU-bound; CPU and memory tuning
move the 1% lows more than GPU settings do. That matches this repo's observed 180 to 350 FPS swing and its focus on
fight-time CPU cuts (particle fallbacks, bone flex, morphing, foot lock, cloth) over further GPU cuts.
